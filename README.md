# DentalFlow website

The clinic's landing page (English, Urdu, Arabic) with the 3D tooth and the booking chat.

```
npm install
npm run dev        # http://localhost:3000 — the chat runs in demo mode until it is connected
```

Try other 3D tooth models at http://localhost:3000/en/model-lab.

Connecting the chat to n8n, the WhatsApp template, the 3D tooth and putting it online: see `../docs/WEBSITE.md`.
